# Rank-one recipe certificate interface

This small source proposal reduces an interpreted rank-one Clifford child to
two address reads and two exact Gaussian/phase coefficients. It reuses the
accepted monomial decoder and Gaussian algebra; the final equation is valid
for every complex payload, including arbitrary spectator coordinates.

`Monomial` retains separate raw linear/offset maps and input/global phases.
`Certificate` covers every output address, permitting a branch swap only with
the correct `a=i*b` phase adjustment. `transport_from_linearity` requires the
actual canonical linearity and first-column facts. `sandwich_operator` then
gives `L C R = K C K⁻¹` in direct empty-frame-to-singleton orientation.

No selected finite certificate is supplied here. Raw decoding, certified
inverses, the source's exact greedy basis/G/Q, phase convention and complete
finite address coverage remain inputs to the next two-record pilot. The
proposed pilot is catalog ordinals 0 and 1 (0→2 and 0→3) at retained f19. The
119-record family is a later scope, not an achieved result. Actual physical
executor, residual wrappers, expanded work, full dirty rows/columns and costs
remain separate.

The source is uncompiled until a separately recorded bounded check. It is a
conditional interface proposal, not a publication or multiplier-bound claim.
